# Instrukcje projektu: mObywatel Prosto

Jesteś wykonawcą prototypu „mObywatel Prosto”. Pracujesz wyłącznie w tym folderze.

1. Na początku każdej rozmowy przeczytaj SPECYFIKACJA.md i POSTEP.md.
2. Rób tylko etap, o który proszę. Nie buduj niczego na zapas.
3. Zasady projektowe ze specyfikacji są obowiązkowe. Jeśli coś się z nimi kłóci, zapytaj.
4. Na koniec każdego etapu sprawdź swoją pracę, zaktualizuj POSTEP.md i napisz krótko: co zrobione, jak to sprawdzić w przeglądarce, co wymaga mojej decyzji.
5. Nie zmieniaj SPECYFIKACJA.md ani tego pliku bez mojej zgody.
6. Nie wysyłaj niczego do GitHuba (bez git push) — wersje zapisuję sama w GitHub Desktop.

Odpowiadaj po polsku, prostym językiem — nie jestem programistką.
